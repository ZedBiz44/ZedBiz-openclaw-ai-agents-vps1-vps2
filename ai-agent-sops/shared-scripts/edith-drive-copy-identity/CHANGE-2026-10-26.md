## Feature purpose

The binary copier preserves a Google-reserved destination ID before its first copy request. It can now accept an approved destination in a different Shared Drive without confusing the destination's Drive ID with the source's.

The old assumption was that source and copied file must have the same `driveId`. The correction checks MD5, size and MIME against the source, while checking the copied file's Drive ID against its approved destination folder.
